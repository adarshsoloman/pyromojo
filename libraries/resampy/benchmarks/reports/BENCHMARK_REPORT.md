## Observations

- Upstream warm execution is the fastest path on large inputs; it is a compiled Numba loop with no per-call protocol or filter-validation cost.
- Native in-process timing measures the public Mojo `resample` entry point, including filter-table preparation and output allocation per call.
- The CLI path is reported separately because it carries process startup, framed I/O, SHA-256 filter validation, and output encoding on every request.
- The CLI ping floor sets the minimum possible CLI cost; the 1:1 rate pair is dominated by that floor because the kernel itself is a copy.
- No universal-speedup claim is made. These numbers characterize this host and the current native implementation; they are not an optimization result.

## Methodology deviations

- Four paths are measured: upstream warm, upstream cold, native in-process, and native CLI. The binding document also lists a Python-to-Mojo interop path; it is unavailable in v0.1.0 and is reported here as a gap.
- The correctness gate is exact SHA-256 equality, stronger than the tolerance proposal in the Phase 1 design.
- CPU affinity uses `os.sched_setaffinity` rather than a `taskset` wrapper; children inherit the single pinned CPU.
- The optional pure-Python floor and optional upstream `parallel=True` variant are not measured.
- Aggregates use median-of-medians rather than the Phase 1 proposal's geometric means; ratios span orders of magnitude and tiny cells would dominate.
- Per-operation peak memory is not isolated; driver and child peak RSS are reported instead.
- Build wall time is measured after removing the output binary, but the Mojo compiler cache state is whatever the installed toolchain provides.

## Exclusions and limitations

- `length=2, 44100:16000` is excluded because the computed output length is 0; upstream requires at least one output sample.
- Only 1-D Float64 `kaiser_fast` is measured. Float32, complex, N-D, `kaiser_best`, and parallel upstream execution are outside scope.
- All timings are single-core pinned. Results are specific to this host and toolchain.
- The coefficient resource was extracted to a temporary directory and deleted; its SHA-256 is recorded above.
