## Sponsor this project

GitHub Sponsors: https://github.com/sponsors/adarshsoloman

Sponsorship supports the ongoing work that this repository depends on:

- porting additional Python libraries to native Mojo
- differential test suites that run the Mojo port against the Python
  reference implementation (currently 545 Python tests, 193 native Mojo
  tests, 266 golden vectors)
- benchmark runs and honest performance reporting
- keeping the ports dependency-free and Apache-2.0 licensed

There are no sponsor-only tiers, private builds, or gated features.
Everything in this repository is and stays public under
[Apache-2.0](LICENSE).
